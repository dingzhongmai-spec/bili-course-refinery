# Execution guide

1. Identify screenshot clues and verify source pages. Record author, series, BV, page, duration and exclusions separately. If no course target exists, report the missing information.
2. Run one lesson first. Reuse installed tools; avoid virtual environments by default. Acquire subtitles/audio and board evidence before expanding scope.
3. Read full transcripts and inspect boards. A 120-second sampling interval is only a starting point; revisit dense or ambiguous passages.
4. Method cards: structural cue, first intuition, why it works, justified operations, conditions, failure modes, simpler alternatives and source location.
5. Example cards: verified statement, necessary derivation, result, boundaries, equality and lost solutions. Label added examples as your own.
6. Perform five actual reviews: coverage, mathematics, recalculation, method choice and layout. Record evidence, fixes and unresolved issues. Counters do not certify review.
7. Deliver numbered equations, the main TeX and PDF, provenance and verification limits. Inspect actual PDF pages after compilation.

Portable convention: use the caller's task directory, manifest.json and progress.json; main source is final/lecture.tex and final PDF is final/lecture.pdf. Avoid personal paths and fixed playlist IDs. Repository screenshots identify tools, not lecturers.

Adapt batches, tools, model size, visual aids, notation and explanations as useful. Preserve source conditions, requested scope, publication rights and cleanup boundaries.
