# 课程讲义的教学设计

用于把已核对的课程材料组织为可独立学习的讲义。它补充证据炼化流程，不替代来源核实或五轮审阅。来源与适配说明见[upstream-notice.md](upstream-notice.md)。

## 1. 先检查材料，再确定组织

在manifest中保留课程范围；任务内用`handout-plan.md`记录已有用户要求、受众与前置知识、讲义结构、重点、目标篇幅（如有）、密度、输出版本与格式、主文件、缺失证据及下一步。更新同一份方案，避免多份“最终稿”。

沿用已有对话和交付约定，已授权制作就继续制作。仅当必需条件、课程范围或交付选择无法推断时询问关键缺项；可以继续不依赖答案的工作。没有指定篇幅时可记录可调整的估计，不为了估计页数阻塞工作。默认沿用本项目解释型LaTeX/PDF讲义；不自动新增教师版、练习册或其他格式。

把材料按实际处理需求登记；这些需求可以同时存在，不是互斥等级：

|材料|处理与证据边界|
|---|---|
|可抽取文字的PDF、TeX、Markdown、字幕|读取所需内容并记录实际读取范围；存在文字层不表示图像与公式已核实|
|扫描页、照片、板书帧|可用AI视觉或可用OCR读取；保存实际识别结果与原图定位，疑点回查原图。登记识别工具及其提供的置信信息，不编造置信分数|
|音视频|取得字幕或ASR和板书帧，保留讲次、分P、时间段及工具版本；ASR只能提供转写线索|
|含嵌入图像的DOCX/PPTX|需要使用原图时优先提取源文件内图像，并核对它在原页的位置、裁切、标注及上下文；提取成功不等于已经查看|
|损坏、受限或无法可靠读取|记录原因、影响条目和替代方案，不能默默跳过或声明已读取|

原始图用于证明板书或题意时保留真实形状、刻度、箭头与标注。整理者重绘示意图可以辅助教学，但标明归属，不能代替证据原图。

## 2. 从知识目录走向学习行动

按已读内容在方案中写知识结构：主题→概念/方法→前置条件与易错点，通常不超过三至四层。用Markdown列表作为可编辑主结构；Mermaid仅在有助于阅读时派生，修改后同步。标记核心、重点、背景、待核验；教学优先级不能由视频时长或重复频率自动决定。

在任务内`coverage.md`维护覆盖矩阵：

|内容ID|学习者能做什么|解释位置|核实例题|练习/诊断（如适用）|易错点/图像|来源定位与核验状态|
|---|---|---|---|---|---|---|

每个纳入知识节点对应一行，涉及的讲次和原课例题可回查。来源定位使用真实BV/分P/时间段或本地文件/页码；尚未取得的位置标待核验。`coverage.md`记录教学覆盖，`manifest.json`记录课程范围，`progress.json`记录真实执行状态，三者互相引用，不用矩阵替代进度证据。

检查两种覆盖：全部指定原课材料是否被处理；学习者是否得到完成目标行动所需的解释与示范。“提到了”“出现过公式”不能自动算会运用。概念回忆可简短，换元、证明、图像解释等行动需有可检验示范；练习只在用户目标需要时增加。

若要求练习，按功能选择即时检测、独立练习、变式或拓展，并标难度、题源或整理者原创。先选能暴露误解的题，再补难度递进，不靠题数配额凑内容。题目较多时增加题型结构与分布统计；同一题有多个功能标签时说明去重口径，标签总数不冒充题目总数。

## 3. 解释、示范、检测形成闭环

方法卡仍保留第一直觉、为什么有效、条件与简单路线比较。教学组织可采用：引出障碍→解释关键变换→完整例题→适用时的小检测→易错反例。学习行动和难度适配读者，不为齐全套用每个环节。

以下是整理者原创的最小演示，不是原课内容，不带虚构时间戳：

- 学习行动：识别根号内函数的导数，并把剩余因子写成新变量。
- 例题：求`∫ x³/√(1+x²) dx`。设`u=1+x²`，则`x³ dx=(u−1)du/2`；结果为`(1+x²)^(3/2)/3−√(1+x²)+C`，实数x。
- 解释重点：变换同时简化根式和微分；不能只说“令u即可”。
- 可选即时检测：求`∫ x/√(1+x²) dx`，并解释为何新积分的系数为1/2。答案是`√(1+x²)+C`，可对答案求导验证。
- 易错检查：漏掉1/2、忘记常数C；原函数求导为原被积函数才算这一步核验。没有运行CAS就不宣称CAS通过。

真实任务将演示行换成已核实的课程题目与来源；独立补题始终保持整理者归属。

## 4. 篇幅、版本与交付

密度可以是提纲、解释型或练习型，依用户目标选择。指定篇幅时记录各节预算及编译后的实际页数。超出预算先删冗余解释、合并重复练习或调整结构；必要推导不能因页数被删掉，也不能静默减少指定讲次与例题。范围与篇幅冲突时报告具体差额并询问取舍，继续可独立完成部分。不得用缩小字号掩盖超长或溢出。

版本与格式是两个维度。用户需要学生/教师版时，从同一内容主稿生成：学生版保留题干、必要提示和作答空间，教师版增加完整解答、教学提示与误区。每个版本检查答案可见性、图像、引用、公式及分页；若用户要答案附录则按要求保留。不要先隐藏再忘记核验。

LaTeX/PDF沿用当前主TeX原地修订。其他格式仅按用户要求且工具实际支持时生成，使用同一内容源，记录转换差异并逐格式验收；安装器就绪不代表已支持Word/PPT导出。用户模板优先，PDF/图片只作为视觉参考，不假称可编辑模板，不强行套用上游物理模板。

并入原五轮审阅：覆盖轮核对知识节点、原课材料与矩阵；数学/复算轮核验例题、补题和答案；思路轮检查示范与检测是否达成学习行动；排版轮检查实际PDF、篇幅和版本答案可见性。交付说明真实覆盖、素材读取边界、实际页数与预算偏差、每种格式的检查范围和未完成项。
