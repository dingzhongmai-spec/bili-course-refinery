选择性吸收 / Selectively adapted:

- 材料可读性、OCR与原图提取边界 / Material readability, OCR and authentic asset extraction.
- 学习行动、知识结构与教学覆盖 / Learner actions, knowledge structure and teaching coverage.
- 例题与练习的教学功能 / Teaching functions of examples and practice.
- 篇幅预算、版本与格式区分、逐版本验收 / Length budgets, editions versus formats and edition-specific QA.

本项目按课程炼化任务重新组织并提供中英文指导，保留截图起点、真实口述/板书、五轮审阅、当前主TeX、Codex运行配置与用户已有授权。不引入上游固定多轮访谈及单独制作批准流程，不改为默认Word，不强制双导图或双版本，不复制物理模板、演示PDF和脚本。已有明确要求优先；AI可自主调整教学组织、解释、工具和示意图，不能改变原题、来源事实、指定范围与完成状态。

This project reorganizes the selected ideas for evidence-backed course refinement in both languages. It retains screenshot intake, actual speech/board evidence, five reviews, the current main TeX, Codex runtime configuration and existing user authorization. It does not import mandatory interview rounds or a separate production approval gate, change the default to Word, require dual maps/editions, or copy physics templates, demonstration PDFs or scripts. User requirements prevail; AI may adapt teaching structure, explanation, tooling and illustrative diagrams while preserving problem conditions, source facts, designated scope and truthful completion states.
