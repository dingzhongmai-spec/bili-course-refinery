# 中文执行指南

1. 截图识别与页面核实：作者、系列、BV、分P、时长、排除项分别登记。没有课程对象时先报告缺项。
2. 一节试跑：检查已有环境，默认不用虚拟环境；先取得字幕或音轨、板书，再扩大范围。
3. 材料核对：读完整口述，查看板书；120秒粗抽帧只作为起点，公式与题目疑点回查更密集片段。
4. 方法卡：题目特征、第一直觉、为什么有效、操作依据、条件与误区、简单路线比较、来源位置。
5. 例题卡：核实原题条件，给必要推导、结果、边界/等号/漏解检查；补题标明归属。
6. 五轮审阅：覆盖→数学→复算→思路→排版；记录实际证据、修改与遗留问题。没有做的检查不能借计数器宣布通过。
7. 交付：编号公式、主TeX与PDF、来源及核验边界。PDF编译成功后再看真实页面。

便携约定：任务目录由调用者给定。维护manifest.json和progress.json，主文件为final/lecture.tex，最终PDF为final/lecture.pdf。不依赖个人路径或固定合集ID。用户上传工具截图时从已有上下文确定课程；不要将工具作者当授课作者。

可自主调整：批次、工具实现、模型规模、图像、解释组织、记号、简单替代解法。不得擅自改变原题条件、范围、发布权限和清理对象。
