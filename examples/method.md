# 方法卡示例：让微分吸收多余的幂

归属：整理者原创演示，不声称取自某一课程。真实课程条目需附BV、分P与已核对的题目时间定位。

题目：计算 `∫ x³/√(1+x²) dx`，实数x。

第一直觉：根号内部的导数是2x，分子中可以拆出x dx，剩余x²可用新变量表示。

为什么有效：令u=1+x²同时处理根号和微分；x³ dx=x²·x dx=(u−1)du/2，因此整个积分变成两个有理幂函数的积分。

必要推导：

```latex
\begin{align}
u&=1+x^2, & du&=2x\,dx,\\
\int\frac{x^3}{\sqrt{1+x^2}}\,dx
&=\frac12\int(u^{1/2}-u^{-1/2})\,du\\
&=\frac13u^{3/2}-u^{1/2}+C\\
&=\frac13(1+x^2)^{3/2}-\sqrt{1+x^2}+C.
\end{align}
```

条件与误区：1+x²恒正，实数范围内根式有定义；此处可直接对所得原函数求导验证，不必强行在全实轴定义换元的单值反函数。不要丢掉du中的系数2。

简单路线比较：三角代换也可行，但需要额外三角恒等式与回代；u=1+x²以更少步骤完成。简单由知识与操作成本决定。

独立核验：对F求导，得到x√(1+x²)−x/√(1+x²)=x³/√(1+x²)。这是一项解析核验；未运行CAS时不能写CAS通过。

可选Wolfram输入：

```wolfram
FullSimplify[D[(1+x^2)^(3/2)/3-Sqrt[1+x^2],x]-x^3/Sqrt[1+x^2], Assumptions -> Element[x,Reals]]
```

预期为0，实际输出由执行者记录。
