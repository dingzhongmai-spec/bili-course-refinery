# 发布材料检查

本包包括本地截图上传启动器、Codex CLI执行适配、中英文skill与说明、原创流程说明、便携脚本与合成教学示例；未包含历史课程原文、视频、板书、完整转写、账号信息或原始聊天日志。

上传前检查实际文件清单；只把本目录作为仓库根目录。`work/` 和其他本地材料由.gitignore排除。若创建新的示例，确认它是原创或具备相应发布许可。上传流程本身与上传课程材料是不同范围。

许可待用户选择：本包未擅自指定MIT或其他开源许可。公开GitHub仓库不自动代表授予所有开源使用权。外部依赖的许可和使用条件归各上游，不能被本包覆盖。

首次发布建议记录：版本号、验证系统和Python版本、哪些步骤实测、哪些仅提供接口/指令。没有执行网络采集、GPU转写或整套课程复现时，不写“全链路已验证”。

本包没有自动推送、自动清理或自动完成审阅的功能。审阅状态必须由实际执行者填写。
