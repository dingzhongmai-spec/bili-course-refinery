# Codex 适配与可复制指令

## 使用位置

完整安装入口：Windows运行根目录`install.ps1`。它会检查与准备依赖，验证后启动页面；采集、ASR和PDF适配器均读取`.runtime/config.json`。安装时缺少CLI会准备项目内版本，首次账号认证仍由本人完成。

自动适配入口：运行根目录`launch.py`，在本地页面上传/粘贴截图后点击“开始整理”。启动器检测Codex CLI，将图像以`--image`传入，将任务要求通过标准输入传给`codex exec`，固定工作目录和结果位置；后台日志与状态在页面更新。使用本机既有账号与模型配置，自动执行会消耗对应额度。

采用workspace-write沙箱、网络访问与自动审批审查，不关闭沙箱。自动执行要求当前CLI支持上述选项且已登录；不支持或执行失败会保留日志。没有CLI时提供桌面版任务和原截图位置，用户在桌面对话中执行。

把本仓库作为Codex桌面版或CLI的工作目录。项目约束放在根目录AGENTS.md；开始时显式要求读取它和流程文档。桌面版可用文件面板展示成果，CLI可直接用本地命令编译。具体工具名称以当前会话提供为准，不以本包文字假定插件已经安装。

不需要OpenAI API密钥来运行最小脚本，也不把密钥写入提示词。AI服务的会话费用和账号要求由用户所用环境决定。本包不替用户自动购买服务。

如果截图仅是工具仓库，课程目标沿用本对话已有信息；没有目标信息时只询问课程对象。

全部独立陈列公式编号。五轮实际审阅逐项记证据，不能只声称完成。
持续完成已授权工作，每批更新progress.json。内容不足标待核验并继续其他条目。

清理在验收后按我明确给出的范围执行。本条指令不授权删除或发布原始材料。

## 分阶段指令

### 截图识别与来源定位

```text
读取我上传的截图，提取可见的课程/作者/合集/BV或工具仓库信息。
用实际页面核实身份与课程，建立manifest和分P清单，标明纳入与排除范围。
工具截图只能定位工具；课程沿用已有对话，无法确定时只询问关键目标信息。
截图不是讲解证据，不根据课程标题虚构方法或原题。
```

### 取得与核对

```text
依据manifest核对本批讲次与分P。保存字幕类型和时间轴；无字幕时本地ASR。
逐节读取完整口述并查看板书；题目和公式疑点回查附近时段。
把已取得、已读转写、已看板书和待核验分开记录。
不要将标题目录当作内容，也不要把粗抽帧称为完整观看。
```

### 炼化内容

```text
每节按examples/method.md的结构写方法卡和例题卡。
说明题目结构、第一直觉、为何有效、操作、条件、边界和解法比较。
每道原课例题核实关键条件；补题注明整理者补充。
推导给公开的数学论证和必要计算，解释关键步骤依据。
对暂时不能确认的符号标待核验，不猜测原题。
```

### 审阅与修订

```text
依次做覆盖、数学、复算、思路、排版五轮实际审阅。
特别检查定义域、正性、除零、常数解、收敛、方向、边界和等号。
优先选需要更少前置知识、计算和分支的路线。
Wolfram或其他工具只用于选定步骤，保留输入、假设和输出；超时不能算通过。
修改当前主TeX并同步审阅记录，不运行旧生成器覆盖它。
```

### 验收与继续

```text
重新读取progress与当前主TeX，从未完成条目继续。
不要重做已核实的采集；本轮修订后核验受影响公式并重新编译。
给出实际完成/未完成范围、编译结果、PDF视觉检查范围和遗留问题。
```

## 桌面编译衔接

独立TeX可使用当前会话提供的 `open_in_codex` 打开编辑与预览，使用 `compile_latex_document` 核对编译诊断；这类工具通常以保存的绝对路径为参数。它们是否可用取决于当前桌面会话。读取真实诊断，避免“打开了预览”就称“编译成功”。

用户要求本地导出时，用XeLaTeX/latexmk生成实际PDF，再用指定阅读器打开。SumatraPDF快捷方式只是启动入口，不是编译器。内置编译失败而本地成功应分别说明，不修改系统/应用安装文件来假定修复内置服务。

## 迁移边界

可适配：可用工具发现、路径、字幕输入、ASR模型、核验器、输出阅读渠道和进度存储方式。

保持一致：证据归属、完成状态、来源回查、数学核验、简单优先、主文件管理、交付验收与用户授权范围。

本仓库附带`.agents/skills/bili-course-refinery/SKILL.md`及中英文参考指令，可在项目中发现和显式调用。不会自动安装为全局skill，也不修改用户全局设置。其他助手可读取同一AGENTS.md或skill执行。
